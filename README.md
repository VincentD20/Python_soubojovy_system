# 🗡️ Python Soubojový Systém

Jednoduchý soubojový systém napsaný v Pythonu, určený pro výuku, experimentování a rozšíření o RPG mechaniky. Projekt demonstruje práci s objekty, třídami, podmínkami a cykly.

## 🔧 Funkce

- Vytváření postav s různými atributy (síla, obrana, zdraví)
- Základní souboj mezi dvěma postavami
- Výpočet poškození na základě atributů
- Záznam průběhu souboje
- Možnost rozšíření o magii, vybavení, nebo více hráčů
